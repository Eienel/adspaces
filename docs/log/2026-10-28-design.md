# Design session — 2026-10-28

## Asked by owner
Make the web app look and feel like https://blink.cash and https://wspr.ai, but be creative and mix them into
something distinctive rather than copying. Look at https://github.com/Leonxlnx/taste-skill for motion ideas.

## Done
- The network was first restricted (proxy 403 for both sites). After the owner allowed all sites, Playwright
  captured both at 1440 + 390 (full scroll, computed styles, fonts, keyframes). wspr.ai is a parked Namecheap
  page. The owner confirmed the intended site is **wisprflow.ai**.
- First pass copied too literally (Blink's glass hero + Wispr's bands). The owner asked for something more
  original, so it was reworked into the **"layout sheet"** concept (ADR-0017, `docs/11-design-system.md`).
- Tokens + concept classes in `apps/web/app/globals.css`. Self-hosted OFL fonts (EB Garamond, Figtree).
  New chrome (bordered nav box, segmented tabs via `components/site-nav.tsx`, logo mark, footer wordmark).
  New home page. All components restyled. Wallet button matches `.btn`.
- Motion: CSS-only load sequence (~1.5s, signature = slot fills + "Booked" stamp), scroll-timeline reveals on
  two sections, one pausable marquee, reduced motion = finished state.
- Seeded dev data (2 creators, 1 business, 1 ad, 1 paid booking) to screenshot every page.

## Verified
- `pnpm typecheck` and `pnpm --filter @adspaces/web build` pass.
- No horizontal scroll at 390px or 1440px on home, signin, listings, listing, dashboard, business, new ad,
  ad board, ad, booking and terms (Playwright `scrollWidth` check).
- Before/after screenshots: `docs/design-screenshots/`. The before shots were taken before the test data existed,
  so the "before" listing/booking pages aren't included.
